My son has a school project that we get to work on together. He needs to build a family tree. The family tree should depict his maternal and paternal ancestry up through his great grandparents.

- First and last name of each individual is required.
- Should be obvious which people are spouses of a person.
- Photos of each individual are required.
- Should include birth date and death date if deceased.
- Should include the person's country of origin, and a flag of that country

An overall map containing pins identifying each person's of origin would be helpful.

The family tree will be presented digitally. It will be shown as part of his school presentation. It must be easily loaded on a variety of devices (eg iPad, laptop connected to a projector, etc) for viewing. Ideally, the project can be loaded from a USB drive, with an internet connection not being required.

The user interaction required for viewing the family tree must be minimal. For example anyone viewing the screen must be able to see the information, without having to manually click each person. A slideshow may be a good example of the level of interaction desired.

The visual interest and attractiveness of the layout/presentation is of utmost importance. Animation is encouraged. A high tech feel is encouraged. It has to look and function very well. We are open to other concepts, but we are imagining a tree from nature to be a fun way to visualizen the graph, rather than a pure chart.

The data structure must be such that my son can input the information of the ancestry. I’m thinking JSON with some examples. His learning opportunity would be to edit the JSON to reflect the family ancestry, as well as learning to save and reference images (portrait, flag, etc) of each person in the correct file path. In addition to learning about ancestry he can learn some basic programming, working with an AI agent (that's you), and creating a visually compelling project.
